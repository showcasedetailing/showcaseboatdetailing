# Showcase Boat Detailing — Website

Premium black & gold mobile boat detailing website for Showcase Detailing LLC (Volusia County, FL).

- `index.html` — home
- `gallery.html` — project gallery (photos in `assets/`, organized via `assets/gallery.json`)
- `services.html` — services (gelcoat correction, wash & protect, teak, ceramic, boat care club)
- `quote.html` — quote request form (composes a text to (386) 315-3633)
- `assets/logo.jpg` — brand logo (black & gold wave badge)

To add/replace photos: drop optimized JPGs into `assets/` and update `assets/gallery.json`
(`src`, `group`, `title`, `service`, `alt` per item).
